# AAKSHANT-CAFE-
A Tkinter-based café billing system for managing customer details, menu items, quantities, payments, GST calculation, and bill generation with a simple user-friendly interface.
☕ Aakshant Café – Billing System

Aakshant Café Billing System is a desktop-based café billing application developed using Python and Tkinter. It provides a simple and user-friendly interface to manage customer details, select food items, calculate bills, and generate receipts.

✨ Features

- ☕ Café menu with food and beverage items
- 🧾 Automatic bill generation
- 👤 Customer name and mobile number
- 💳 Payment mode selection — Cash, UPI, Card
- 🔢 Quantity selection
- ➕ Add items to the order
- ➖ Remove the last added item
- 💰 Automatic subtotal calculation
- 🧮 GST calculation
- 🧾 Detailed bill receipt
- 🔄 Clear bill option
- 🚪 Exit option
- 🎫 Random bill number generation
- 📅 Date and time display

🛠️ Technologies Used

📋 How It Works

1. Enter the customer's name and mobile number.
2. Select the payment method.
3. Choose an item from the menu.
4. Select the required quantity.
5. Click Add Item.
6. Add multiple items if required.
7. Click Generate Bill to create the final receipt.
8. The system automatically calculates 18% GST and the grand total.
9. Use Clear to start a new bill.

🚀 How to Run

Make sure Python is installed on your system.

python app.py

Tkinter is included with most standard Python installations.
